# 실험 1: 디자인 시스템

> 2026-11-03 사용자 확인. 시험 실행 전에 바꾼 것은 아래 "확인 뒤 바꾼 것"에 적는다.

## 질문
- 작은 프로젝트에서 디자인 시스템을 어디까지 갖춰야 가장 효율적인가?

## 고정값
- 모델: Sonnet 5.5, effort low
- 실행 환경: React + Vite + Tailwind, 390×844
- 서버: 가짜 API
- 모든 조건에 시안 · 설명 패널 · 지도 · SDD · 엔티티를 준다
- 모든 조건에 기본 게이트(빌드 · 기본 동작)를 둔다
- 단계마다 새 세션으로 시작하고, 작업 폴더만 이어 쓴다

## 비교 조건

| 조건 | 토큰 | 컴포넌트 | 토큰 · 부품 린트 |
|---|---:|---:|---:|
| A | X | X | X |
| B | O | X | X |
| C | O | O | X |
| D | O | O | O |

- 조건 4개 × 3회 = 12회, 회당 4단계
- 컴포넌트는 에이전트가 시안의 컴포넌트 페이지를 보고 한 번 만든다
- 만드는 비용을 기록해 C · D의 전체 비용에 더한다
- 만든 결과는 기준 구현으로 검증한 뒤 C · D에 똑같이 준다

## 단계

| 단계 | 할 일 | 시안 | 채점 |
|---|---|---|---|
| 1 | 과목 선택 시트 | 15 + 상태 4장 | 25개 |
| 2 | 과목 관리 | 16 | 10개 |
| 3 | 계획 추가 시트 | 32 | 9개 |
| 4 | 디자인 변경 요청 | 없음 | 9개 + 동작 재검사 |

## 채점 규칙

### 2단계: 과목 관리

| 번호 | 상황 | 기대 동작 |
|---|---|---|
| M1 | 과목 줄 | 색 · 이름 · 표준 과목 표시 |
| M2 | 보관한 과목 | 목록에서 숨기고 "보관한 과목 N개" 표시 |
| M3 | 이름 16자 | 추가되지 않음 |
| M4 | 같은 이름 | 추가되지 않음 (서버 409 허용) |
| M5 | 표준 과목 | 8개 표시, 순서 고정 |
| M6 | 표준 과목 안 고름 | 추가되지 않음 |
| M7 | 색 | 7개 중 1개 선택 |
| M8 | 추가 | 이름 · 표준 과목 · 색으로 요청 |
| M9 | 추가 성공 | 목록에 새 과목 표시 |
| M10 | 과목 20개 | 추가되지 않음 (서버 409 허용) |

### 3단계: 계획 추가

| 번호 | 상황 | 기대 동작 |
|---|---|---|
| P1 | 처음 열기 | 제목 "계획 추가" |
| P2 | 과목 줄 누름 | 과목 선택 시트 열림, 고르면 반영 |
| P3 | 시간 | 시작 · 종료 입력 칸 2개 |
| P4 | 종료가 시작보다 빠름 | 저장되지 않음 |
| P5 | 겹치는 계획 | "겹치는 계획이 있어요" 표시, 저장 가능 |
| P6 | 반복 | 안 함 · 매일 · 평일 · 요일 선택 |
| P7 | 알림 | 토글로 켜고 끔 |
| P8 | 딱지 안내 | 시안 문구 표시 |
| P9 | 저장 | 과목 · 시간 · 반복 · 알림으로 요청 |

### 4단계: 디자인 변경

| 번호 | 요청 | 확인 |
|---|---|---|
| C1 | 주 버튼 높이 52 → 48 | 화면 3개에서 계산된 값 |
| C2 | 주 버튼 모서리 18 | 화면 3개에서 계산된 값 |
| C3 | 선택한 칩 배경 `#067a57` | 화면 3개에서 계산된 값 |

- 변경 뒤 1~3단계 동작을 다시 검사해 깨진 비율을 잰다

## 시안 기준
- 16 과목 관리는 수정 페이지의 표준 과목 8개 판을 쓴다
- 시간은 휠 피커 대신 웹 입력 칸으로 바꾼다

## 확인 뒤 바꾼 것 (시험 실행 전)
- C2: 14는 이미 쓰는 구현이 있어 바꾸지 않아도 통과하므로 18로 올렸다
- C3: 같은 요청을 모든 조건에 주려고 색을 값으로 적고, 반복 칩을 넣어 화면 3개를 맞췄다
- M3 · M6 · P4: 미리 끄는 구현과 눌렀을 때 막는 구현을 모두 받는다

## 실행 뒤 결정 (2026-11-03)
- D 3회차는 크레딧 소진으로 끊겼고, 다시 돌리지 않는다
- 다음 실험은 12회가 아니라 3번만 돌리고, 개발 효율을 함께 잰다

## 채점하지 않는 것
- 끌어서 순서 변경, 밀어서 보관 · 삭제, 과목 수정, 복원
- 계획 수정 모드, 요일 세부 선택, 10분 단위
- 칩 모양: 15는 테두리형, 16은 채움형으로 시안이 달라 C3의 선택 배경만 본다
