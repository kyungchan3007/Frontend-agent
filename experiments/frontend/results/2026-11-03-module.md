## 읽는 법
- **정답률 차이는 없다**: 공통 모듈은 처음 만드는 품질을 바꾸지 않았다
- **차이는 고칠 때 난다**: API 변경에 A는 파일 3개, B · C는 1개를 고쳤다
- **미리 만들 필요는 작다**: C는 준비 비용 없이 B와 같은 변경 범위를 얻었다
- **미리 만들면 새 화면은 빠르다**: B가 가장 빨랐지만 준비 비용까지 더하면 가장 비쌌다
- **변경 2번으로는 A가 손해 보지 않았다**: 전체 비용은 A가 가장 낮았다. 변경이 잦을수록 달라질 수 있다
