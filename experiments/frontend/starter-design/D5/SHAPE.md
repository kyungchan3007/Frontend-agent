# 설계 D: 상태는 Props, 내용은 children

공통 컴포넌트가 모양과 상태를 책임지고, 안에 들어갈 내용은 화면에서 넣는다.

```text
src/ui/        버튼, 칩, 입력, 시트 등 공통 컴포넌트
src/*.tsx      화면
```

- 화면은 `src/ui` 컴포넌트에 `className`을 넘기지 않는다. `variant`, `size`, `fullWidth`, `loading`처럼 모양과 상태를 고르는 옵션만 넘긴다
- 여백 같은 배치는 화면에서 감싸는 `div`로 정한다
- 아이콘이나 작은 글자처럼 안에 들어가는 내용은 옵션으로 만들지 않고 `children`으로 넣는다
- 새로운 모양이나 상태가 필요할 때만 `src/ui` 컴포넌트에 옵션을 더한다

## 어디에 둘지 판단하는 기준

먼저 요청이 어느 화면까지 바꾸라는 것인지 본다. 요청하지 않은 화면의 모습이 달라지면 안 된다.

| 상황 | 둘 곳 |
|---|---|
| 모든 화면에서 항상 같음 | 공통 컴포넌트 안 |
| 정해진 종류 중 화면이 고름 | 공통 컴포넌트의 옵션 |
| 여러 화면이 쓰지만 쓸지 말지는 화면마다 다름 | `src/ui`의 작은 컴포넌트 + `children` |
| 한 화면에서만 씀 | 그 화면의 `children` |

- 예: 별 표시를 두 화면에서만 쓴다면 `src/ui/StarMark.jsx`에 모양을 두고, 쓰는 화면에서 `{on && <StarMark />}`로 넣는다
- 새로운 색이나 크기는 `variant`, `size`에 값을 더한다. 화면에서 `<button>`을 직접 만들지 않는다
