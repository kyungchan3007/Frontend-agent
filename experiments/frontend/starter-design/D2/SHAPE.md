# 설계 D: 상태는 Props, 내용은 children

공통 컴포넌트가 모양과 상태를 책임지고, 안에 들어갈 내용은 화면에서 넣는다.

```text
src/ui/        버튼, 칩, 입력, 시트 등 공통 컴포넌트
src/*.tsx      화면
```

- 화면은 `src/ui` 컴포넌트에 `className`을 넘기지 않는다. `variant`, `size`, `fullWidth`, `loading`처럼 모양과 상태를 고르는 옵션만 넘긴다
- 여백 같은 배치는 화면에서 감싸는 `div`로 정한다
- 아이콘이나 작은 글자처럼 안에 들어가는 내용은 옵션으로 만들지 않고 `children`으로 넣는다
- 새로운 모양이나 상태가 필요할 때만 `src/ui` 컴포넌트에 옵션을 더한다

## 어디에 둘지 판단하는 기준

- **컴포넌트의 상태에 항상 따라오는 표시:** 컴포넌트 안에 두고 Props로 켠다. 화면이 표시를 직접 그리지 않는다
  - 예: `Toggle`의 켜짐 모양은 `checked`로 정해진다
- **이 화면에서만 들어가는 내용:** `children`으로 넣는다. 공통 컴포넌트를 고치지 않는다
  - 예: 버튼 하나의 글자 옆 화살표
  - 공통 컴포넌트를 쓰는 다른 화면의 모습이 달라지면 안 된다
- **같은 내용을 두 번째 화면에서 또 쓸 때:** 복사하지 않고 `src/ui`에 작은 컴포넌트로 올린다
  - 예: 두 화면에 들어가는 별 표시는 `<StarMark />`로 만든다
- **새로운 색이나 크기:** `variant`, `size`에 값을 더한다. 화면에서 `<button>`을 직접 만들지 않는다
