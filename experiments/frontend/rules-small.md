# 소형 과제 채점 규칙

> 2026-11-02 확정. 출처는 시안 화면과 설명 패널이다.

| 번호 | 상황 | 기대 동작 |
|---|---|---|
| S1 | 처음 열기 | 마지막 공부 과목이 선택됨 |
| S2 | 목록 순서 | 최근 사용 순 |
| S3 | 보관한 과목 | 목록에서 숨김 |

| S6 | 시작 | 세션 생성 후 측정 화면 이동 |
| S7 | 과목 관리 | 과목 관리 화면 이동 |
| E1 | 이름 15자 | 오류 없음, 추가 켜짐 |
| E2 | 이름 16자 | 칸 아래 오류, 16/15, 추가 꺼짐 |
| E3 | 15자로 줄임 | 오류 사라짐, 추가 켜짐 |
| D1 | 같은 이름 | 칸 아래 오류, 추가 꺼짐 |
| D2 | 이름 바꿈 | 오류 사라짐, 추가 켜짐 |
| D3 | 서버 409 이름 중복 | 같은 문구, 칸 아래 |
| M1 | 과목 20개 | 칸 아래 오류, 추가 꺼짐 |
| M2 | 서버 409 개수 초과 | 같은 문구, 칸 아래 |
| Z1 | 과목 0개 | 안내 문구 2줄 |
| Z2 | 과목 0개 | 추천 칩 8개, 순서 고정 |
| Z3 | 칩 누름 | 파란색 과목 생성 후 측정 시작 |
| Z4 | 새 과목 추가 누름 | 입력 폼 열림 |
| O1 | 오프라인 | 배너 표시 |
| O2 | 오프라인 시작 | 토스트 표시, 요청 없음 |
| O3 | 오프라인 칩 | 토스트 표시, 요청 없음 |
| R1 | 서버 409 이미 측정 중 | 진행 중 세션으로 이동 |
| R2 | 측정 중에 열기 | "이 과목으로 바꾸기" 버튼 |

## 사용자 결정
- 오프라인은 배너와 토스트를 함께 띄운다 (UI 가이드의 토스트 금지보다 패널 우선)

## 채점하지 않는 것
- 시트를 끌어내려 닫기
- 애니메이션
- 정하지 않은 값: 폼 기본 색 · 기본 표준 과목
