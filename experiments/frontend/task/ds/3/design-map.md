## 이번에 만들지 않는 것
- 수정 모드와 삭제, 요일 세부 선택
- 휠 피커. 웹에서는 시간 입력 칸으로 대신한다

## 정해 둔 것
- 겹칠 때 안내 문구는 "겹치는 계획이 있어요"
- 시안의 딱지 안내 문구를 한 글자까지 같게 쓴다
