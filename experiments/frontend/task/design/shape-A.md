# 설계 A: 옵션형 공통 컴포넌트

공통 컴포넌트가 모양을 책임지고, 화면은 옵션만 고른다.

```text
src/ui/        버튼, 칩, 입력, 시트 등 공통 컴포넌트
src/*.tsx      화면
```

- 화면은 `src/ui` 컴포넌트에 `className`을 넘기지 않는다. `variant`, `size`, `fullWidth` 같은 옵션만 넘긴다
- 여백 같은 배치는 화면에서 감싸는 `div`로 정한다
- 화면에서 쓰는 버튼 · 칩 · 입력 · 시트의 모양을 화면 파일에 직접 쓰지 않는다
- 새로운 모양이 필요하면 `src/ui` 컴포넌트에 옵션을 더한다
