# 작업: 버튼 변형 추가

화면 담당의 요청입니다. 시안은 없고, 아래 내용대로 만듭니다.

1. 계획 추가 화면의 `저장하기` 버튼: 저장 응답이 오기 전까지 누를 수 없고, 글자 앞에 작은 스피너를 보여 준다
2. 과목 관리 화면의 `과목 추가하기` 버튼: 글자 왼쪽에 ＋ 아이콘을 넣는다
3. 홈 화면의 측정 시작 버튼: 글자 아래에 작은 글자로 선택한 과목의 `오늘 0:00`을 보여 준다

## 지킬 것
- 스피너, 아이콘, 작은 글자는 `aria-hidden`으로 둔다. 버튼을 읽는 이름은 바뀌지 않는다
- 다른 동작과 문구는 바꾸지 않는다
- 외부 패키지를 새로 더하지 않는다
- `SHAPE.md`의 설계를 따른다
