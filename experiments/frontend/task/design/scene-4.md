# 작업: 시험 일정 화면 추가

`/exams` 주소에 시험 일정을 추가하는 바텀시트 화면을 만듭니다. 시안은 없고, 이 앱의 다른 화면과 어울리게 만듭니다.

- 제목: `시험 일정 추가`
- 시험 이름 입력 (최대 15자, 넘으면 오류 문구)
- 과목 선택 (과목 목록에서 하나)
- 날짜 입력
- `시험 하루 전 알림` 켜고 끄기
- `저장하기` 버튼: 이름과 날짜가 있어야 누를 수 있다. `POST /api/exams`로 `{ name, subjectId, date, notify }`를 보내고, 201이면 홈으로 간다

## 지킬 것
- 다른 화면의 동작과 문구는 바꾸지 않는다
- 외부 패키지를 새로 더하지 않는다

## 확인
- `node tools/check.mjs`가 GATE PASS다
