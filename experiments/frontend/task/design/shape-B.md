# 설계 B: 조합형 공통 컴포넌트

공통 코드는 작은 조각만 주고, 화면에서 조립한다.

```text
src/ui/        작은 조각 (버튼 틀, 입력 틀, 시트 틀, 색 스타일 값)
src/*.tsx      화면. 조각을 조립해 쓴다
```

- `src/ui` 컴포넌트는 `children`과 `className`으로 밖에서 채우게 열어 둔다
- 컴포넌트에 `variant` 같은 모양 옵션을 두지 않는다. 자주 쓰는 스타일은 `src/ui`에 값으로 내보낸다
- 입력의 오류 문구나 시트의 제목처럼 나눌 수 있는 부분은 별도 조각으로 나눈다
- 새로운 모양이 필요하면 `src/ui`를 고치지 않고 화면에서 조립한다
